# Админу

Всё делается **в личке бота**.

---

## Создать тренировку

**Одной строкой** — самый быстрый путь:

```
Завтра в 19:30, Центральный стадион, интервальная 6×400
```

Порядок: **когда, где, что** через запятые. Бот понимает «завтра»,
«28 августа», «30.08», «во вторник», время с минутами и без.

Дальше — предпросмотр с кнопками **✅ Опубликовать / ✏️ Редактировать /
❌ Отменить**.

**По шагам:** `/trainings` → ➕ Создать тренировку.

## Управление

`/trainings` → 📅 Ближайшие или 📝 Черновики → выбрать тренировку.

| Кнопка | Что делает |
|---|---|
| 📢 Опубликовать | пост в чат со сбором участников |
| 🔄 Опубликовать заново | поднять пост наверх ветки: старый убирается, новый шлётся следом |
| ✏️ Редактировать | дата, время, погода, план, что взять, место, ссылка, заметки |
| 🌦️ Обновить погоду | подтянуть прогноз заново |
| 👥 Участники | поимённо: кто идёт, кто может, кто нет |
| 🔔 / 🔕 | напоминания по этой тренировке |
| 🔁 Повторить | копия на неделю вперёд |
| 🚫 Отменить | пост остаётся в чате с пометкой «🚫 ОТМЕНЕНА», опрос закрывается |
| 🗑 Удалить | сносит пост, опрос и скриншоты из чата, тренировку — из базы |

**Отменить и удалить — разное.** Отмена оставляет пост: пришедшие увидят,
что сбора не будет. Удаление стирает всё — это для тренировок, заведённых
по ошибке или задублированных. Бот переспросит и предупредит, сколько
приходов уйдёт вместе с ней: они пропадут из рейтинга безвозвратно.

Сообщения старше 48 часов Telegram удалять не даёт — такие останутся в чате,
бот напишет, сколько убрать не вышло. Сама тренировка удалится в любом случае.

**План и «что взять» — по пункту на строку, без буллетов.** Точки бот
расставит сам. **Заметки** — по абзацу на строку, идут в конец поста
(платный вход, предупреждения).

Правка опубликованной тренировки **перезаписывает пост**, новый не создаётся.
Нужно, чтобы пост снова оказался внизу ветки — жми **🔄 Опубликовать заново**,
сколько угодно раз. Старый пост с опросом при этом убираются, чтобы не было
двух сборов на одно занятие.

⚠️ **Новый опрос начнётся пустым** — перенести голоса Telegram не даёт. Кто
отмечался, бот помнит: напоминания придут им же, и в 👥 Участники они видны.
Но в самом опросе люди будут числиться неответившими, пока не нажмут снова.

## Что бот делает сам

| Когда | Что |
|---|---|
| 10:00 | черновик на ближайшие вт/чт по прошлой тренировке того же дня недели → тебе в личку |
| 08:00 | обновляет погоду в постах сегодняшних тренировок |
| за 24 и 3 ч | напоминает тем, кто нажал «Буду» |
| 09:00 | утренний пост челленджа в беседу |
| 21:00 | пингует тех, кто ещё не сдал кружок |
| 00:00 | закрывает день, фиксирует пропуски |
| 00:05 | итоги дня + топ месяца в беседу |
| 00:30 | бэкап базы, файл тебе в личку |
| сб 12:00 | сводка недели |
| каждые 10 мин | досылает потерянные карточки судьям |

**Авто-черновик берёт прошлую тренировку того же дня недели**: вторник по
вторнику, четверг по четвергу. Место, план, экипировка и ссылка переносятся,
**погода очищается** — её и правишь. Заработает после первой публикации:
копировать пока не с чего.

## Команды

| Команда | Что делает |
|---|---|
| `/trainings` | меню тренировок |
| `/dashboard` | участники, сдачи сегодня, средний процент |
| `/export` | XLSX со всеми сдачами и вердиктами |
| `/backup` | бэкап базы прямо сейчас |
| `/chatid` | id чата и топика (в форуме нужны оба) |
| `/broadcast <текст>` | пост в беседу от имени бота |
| `/ban <id> [причина]` · `/unban <id>` | блокировка |
| `/undo <id>` | отменить **любое** решение судьи, без ограничения по времени |
| `/simulate_day <ГГГГ-ММ-ДД>` | прогнать закрытие дня (только в тестовом режиме) |
| `/wipe_test` | стереть тестовые данные (только в тестовом режиме) |

Админ автоматически считается судьёй и может судить свои сдачи — у обычного
судьи это заблокировано. Учитывай при проверке.

## Про топики

Чат клуба — **форум**, поэтому одного `chat_id` мало: у каждого топика свой
`message_thread_id`. Узнать — написать `/chatid` **внутри нужного топика**.

Кружки принимаются **только из топика кружков**. Брошенный в другую ветку
кружок бот проигнорирует — иначе люди путали бы топики и получали случайные
зачёты.

Отчёты со Стравы принимаются **из топика «Приходы»** — там реплай не нужен,
бот сам находит тренировку по времени. Реплай на пост тренировки в «Тренировках»
тоже работает, как раньше.

## Настройки

`.env` на сервере, меняются без правки кода.
После правки — `sudo systemctl restart challenge-bot`.

| Что | Переменная |
|---|---|
| задание челленджа | `CHALLENGE_TASK` |
| минимальная длина кружка | `MIN_DURATION_SEC` |
| граница суток | `DAY_BOUNDARY_HOUR` (0 = полночь) |
| дни авто-черновиков | `TRAINING_DRAFT_WEEKDAYS` (`tue,thu`) |
| за сколько часов напоминать | `TRAINING_REMINDERS` (`24,3`) |
| слово дня | `DAILY_CODE_ENABLED` (сейчас выключено) |
| чат клуба | `PARTICIPANTS_CHAT_ID`, `TRAININGS_CHAT_ID` |
| топик кружков | `PARTICIPANTS_THREAD_ID` |
| топик тренировок | `TRAININGS_THREAD_ID` |
| топик приходов | `CHECKINS_CHAT_ID`, `CHECKINS_THREAD_ID` |
| окно приёма отчётов | `CHECKIN_WINDOW_HOURS` (48) |
| уборка скриншотов | `CHECKIN_CLEANUP_HOURS` (сейчас 0 — топик приходов и есть история) |
| судьи и админы | `JUDGE_IDS`, `ADMIN_IDS` |
| цитаты и похвалы | `data/quotes.json` |

**Добавить судью:** дописать его `telegram_id` в `JUDGE_IDS` через запятую
и перезапустить. Узнать id — попросить написать боту, потом `/judges`
покажет всех и тех, кто ещё не запускал бота.

## Переключение в бой

```bash
sudo -u challenge sed -i 's/^TEST_MODE=true/TEST_MODE=false/' /opt/challenge-bot/.env
sudo systemctl restart challenge-bot
```

Создастся боевой челлендж со стартом из `CHALLENGE_START_DATE`.

⚠️ **Участия из тестового не переносятся** — все жмут `/start` заново.
Поэтому переключать надо заранее, а не в день старта, иначе люди будут
регистрироваться вместо того, чтобы вставать в планку.

## Если что-то не так

**Бот не видит кружки в беседе** — включён privacy mode. @BotFather →
`/setprivacy` → Disable, потом удалить бота из беседы и добавить заново.
Либо просто сделать его админом беседы. Бот сам пишет об этом в лог при старте.

**Кнопка крутится и ничего не делает** — смотри логи, неразобранные нажатия
туда пишутся с текстом кнопки.

**Скриншот не засчитался** — в топике «Приходы» бот ищет тренировку, которая
уже прошла, за последние `CHECKIN_WINDOW_HOURS` часов и по которой у человека
ещё нет зачёта. Нет такой — отчёт не примется. Вне этого топика по-прежнему
нужен ответ на пост тренировки.

```bash
sudo journalctl -u challenge-bot -f      # живые логи
systemctl status challenge-bot           # состояние
ls /var/lib/challenge-bot/backups        # бэкапы, последние 14
```

**Обновить код:** локально `rsync` в `/opt/challenge-bot`, затем
`alembic upgrade head` и `systemctl restart challenge-bot`. Проект не в git,
поэтому `git pull` на сервере не сработает.
